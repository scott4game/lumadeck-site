Privacy policy

LumaDeck stores host names, user names, endpoints and SSH public keys locally. Remembered passwords are optional and stored in the app's device-only iOS Keychain. Password AutoFill is provided by the user's chosen iOS credential provider. Screen updates, credentials, keyboard and pointer events, and optional clipboard data travel inside an authenticated SSH tunnel to the configured Mac. Bonjour discovery advertises or looks up service metadata on the local network; it carries no credentials. No LumaDeck account or relay is required. Saved connection thumbnails may contain desktop content; delete the saved computer to remove its thumbnail and app-stored password.

When you copy a connection configuration, its address, ports and known public host key can be transferred using the system clipboard. The exported configuration excludes your password. Only share it with intended recipients.
